# Marketplace Laboratory

Interactive single-supplier / single-consumer supply-and-demand model.

## Features

- Interactive linear supply and demand curves
- Automatic market equilibrium (Q* and P*)
- Cost shock
- Benefit boost
- Supply tax
- Demand tax
- Producer surplus
- Consumer surplus
- Tax revenue
- Total gains
- Reset button
- Responsive modern dashboard interface

## Run locally

Open `index.html` in a web browser.

No server, database, framework, or build process is required.

## Publish with GitHub Pages

1. Push `index.html` and this `README.md` to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select your main branch and **/ (root)**.
5. Save.
6. GitHub will provide the public Pages URL.

The model is entirely client-side, so it can be hosted as a static GitHub Pages site.
